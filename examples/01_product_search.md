# Example 1: Catalog search with filters, then payment options

- **Scenario:** A customer looks for acoustic guitars up to R$ 1,000, then asks about installments and PIX for one of them.
- **Demonstrates:** Filtered catalog search (sorted, truncated to 10 of 12, unavailable products hidden) and deterministic payment math: 10x is not allowed because the installment would fall below the R$ 100 minimum, so the tool returns the real maximum.
- **Tools called:** `calculate_payment_options`, `get_product_details`, `search_products`
- **Model:** `gemini-3.5-flash-lite`
- **Simulated store date (`STORE_NOW`):** `2026-03-25T10:30` (Wednesday, Campo Grande time)
- **Generated by:** `uv run python scripts/generate_examples.py` (real model output, not edited). Tool calls are shown as small notes.

---

<sub>🔧 `search_products(only_available=true, max_price=1000, category="violões")`</sub><br>

**Cliente:** Dá pra parcelar o Tagima Woodstock em 10x?

<sub>🔧 `get_product_details(product_name="Tagima Woodstock")`</sub><br>
<sub>🔧 `calculate_payment_options(is_promotional_price=false, amount=899)`</sub><br>
