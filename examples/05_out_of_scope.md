# Example 5: Out of scope requests and store information

- **Scenario:** A customer asks for accessories, for an instrument category the store does not carry, for help with homework, and for the store's address and hours.
- **Demonstrates:** Accessories redirected per the manual without inventing partner stores; an empty category reported as not carried (not as out of stock); an unrelated request politely declined; store information answered from the policies.
- **Tools called:** `search_policies`, `search_products`
- **Model:** `gemini-3.5-flash-lite`
- **Simulated store date (`STORE_NOW`):** `2026-03-25T10:30` (Wednesday, Campo Grande time)
- **Generated by:** `uv run python scripts/generate_examples.py` (real model output, not edited). Tool calls are shown as small notes.
