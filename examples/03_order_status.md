# Example 3: Order status with identity verification

- **Scenario:** A customer asks about an order. The first email does not match the order's customer; the second one does.
- **Demonstrates:** Identity check (order number + email or phone, same generic message for a wrong contact or an unknown order); greeting by first name; a shipped order whose estimated delivery is already in the past is flagged as delayed, so the agent apologizes, shares the tracking code and offers the staff contacts.
- **Tools called:** `get_order_status`
- **Model:** `gemini-3.5-flash-lite`
- **Simulated store date (`STORE_NOW`):** `2026-03-25T10:30` (Wednesday, Campo Grande time)
- **Generated by:** `uv run python scripts/generate_examples.py` (real model output, not edited). Tool calls are shown as small notes.
