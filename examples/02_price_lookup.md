# Example 2: Price lookup, expired and active promotions, out of stock

- **Scenario:** A customer checks prices, asks about a promotion that has expired, then about one that is active, and finally about a product that is out of stock.
- **Demonstrates:** Exact prices from the data; an expired promotion reported transparently with the current price; an active promotion shown with original price, discount % and promotional price, with no PIX discount on top (promotions are not cumulative); alternatives for an out-of-stock product.
- **Tools called:** `calculate_payment_options`, `get_product_details`
- **Model:** `gemini-3.5-flash-lite`
- **Simulated store date (`STORE_NOW`):** `2026-03-25T10:30` (Wednesday, Campo Grande time)
- **Generated by:** `uv run python scripts/generate_examples.py` (real model output, not edited). Tool calls are shown as small notes.
